How to read the city▾

Make a read-only key

  1. Open RevenueCat, then Project settings → API keys.
  2. Click + New API key, name it App City, version V2.
  3. Set every permission group to No access, then Charts metrics permissions to Read.
  4. Click Generate and copy the key once.

Your tower

Your browser reads the six numbers from RevenueCat once, right now. The key then lives on the server, for the refresh every day at 04:00 UTC, and is never shown to anyone.
